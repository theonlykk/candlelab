# ADR-032 — Multi-Instrument M15/H1 Startup Backfill

**Date:** 2026-04-29
**Status:** Accepted
**Repo:** theonlykk/candlelab
**Author:** Khalid Khan (Lead Engineer)
**Reviewer:** Gemini (Staff Architect)

---

## Context

ADR-030 Phase 3 made `backfill_instrument()` interval-aware and
extended the scheduler to loop `["5m", "15m", "1h"]` per cycle.
However `_backfill_all_worker()` — the startup daemon that backfills
all instruments — remained hardcoded to `DEFAULT_INTERVAL = "5m"`.

The scheduler only processes one instrument per 5-minute cycle
(the most recently viewed). Instruments not recently visited never
received M15/H1 backfills. Active non-M5 strategies (Sharp Violet
Falcon NZD/USD M15, Wind Sage Raven USD/CAD M15) had zero M15 rows
in `oanda_candles`, producing zero signals in backtests and Theo P&L.

## Decision

Option A — Unconditional Sweep. Extend `_backfill_all_worker()` to
nest an interval loop `["5m", "15m", "1h"]` inside the instrument
loop.

**Rejected:**
- Option B (Strategy-driven backfill): introduces circular dependency
  between data ingestion layer and strategy state layer. Creates a
  race condition for newly created strategies.
- Option C (Separate APScheduler job): overlapping scheduler concerns,
  lock contention risk on `_backfill_in_progress`, does not fix the
  startup gap.

## Changes

- `data.py`: `_backfill_all_worker()` now loops
  `["5m", "15m", "1h"]` per instrument. Exception handling and
  `time.sleep(1)` rate limiting maintained per iteration.

## Consequences

- All instruments have 30d+ history for all core timeframes within
  ~36 seconds of deployment (36 sequential fetches, 1s apart).
- `_INITIAL_BARS["15m"] = 4000` provides ~41 trading days (~60
  calendar days) of M15 history — sufficient for the 30d backtest
  plus 200-bar warmup.
- No coupling between data layer and strategy state layer.
- `backfill_instrument()` is idempotent — re-running on restart
  only fetches the gap since last stored bar.
- Future timeframes (H4, D1) require only adding to the interval
  list and `_INITIAL_BARS`.

## Negative Space

- Does NOT change `backfill_instrument()`.
- Does NOT change `scheduler.py`.
- Does NOT change `_backfill_all_worker()`'s threading model.
- Does NOT add a `granularity` column to `executor_poll_log`.
- Does NOT touch any route handlers.
