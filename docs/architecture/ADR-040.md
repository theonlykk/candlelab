# ADR-040 — Timeout Bar Count Alignment: Signal Anchor

**Date:** 2026-05-01
**Status:** Accepted
**Repo:** theonlykk/candlelab
**Author:** Khalid Khan (Lead Engineer)
**Reviewer:** Gemini (Staff Architect)

---

## Context

`_scan_tp_sl_timeout()` calculated `bars_remaining` anchored to the
entry bar (`fill_idx`):
`bars_remaining = timeout_bars - (fill_idx - sig_idx)`

The executor anchors timeout to the signal bar:
`timeout_at = signal_ts + timedelta(minutes=minutes_per_bar * timeout_bars)`

This produced a one-bar discrepancy. For Sharp Violet Falcon (M15,
timeout=20): executor closed at 03:30 bar, simulator closed at 03:45
bar — different prices, different outcomes (LOSS vs WIN on the same
trade).

## Decision

Option B — Anchor `bars_remaining` to `sig_idx`:
`bars_remaining = max(0, (sig_idx + timeout_bars - fill_idx) - 1)`

The `-1` accounts for `_next_open_exit` stepping forward +1 to get
the exit price. `max(0, ...)` protects against fill delays exceeding
timeout.

**Rejected:**
- Option A (subtract 1 from existing formula): patches symptom not
  root cause. Only correct when fill_idx - sig_idx == 1.
- Option C (accept discrepancy): WIN/LOSS outcomes differ between
  Theo and OANDA on the same trade — unacceptable.

## Verification

Sharp Violet Falcon 30/04 22:30 SELL (M15, timeout=20):
- sig_idx=0 (22:30), fill_idx=1 (22:45)
- bars_remaining = max(0, (0+20-1)-1) = 18
- Loop scans bars 2..19 (22:45..03:15)
- Timeout: _next_open_exit from bar 19 → bar 20 (03:30)
- Exit at 03:30 bar open — matches executor exactly ✅

## Consequences

- Simulator and executor timeout now anchored identically to signal.
- 30d backtest results will shift slightly — this is correct, not a
  regression. Previous results were artificially distorted by one
  extra bar of duration.
- `max(0, ...)` guard handles edge case where fill delay exceeds
  timeout window.

## Negative Space

- Does NOT change `oanda-trading` executor logic.
- Does NOT change the executor wall-clock timeout mechanism.
- Does NOT change any other function in `simulation_engine.py`.
