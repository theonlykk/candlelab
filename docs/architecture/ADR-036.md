# ADR-036 — 30d Backtest Blotter in Trade Detail Page

**Date:** 2026-04-30
**Status:** Accepted
**Repo:** theonlykk/candlelab
**Author:** Khalid Khan (Lead Engineer)
**Reviewer:** Gemini (Staff Architect)

---

## Context

The My Strategies card showed a 30d backtest stat (signals, win_pct,
cum_net) but the raw signal list was never exposed to the user. This
created a black-box experience and made it impossible to diagnose
chart/backtest signal discrepancies without Railway debug logging.

## Decision

Add a 30d Backtest Blotter section to the trade detail page, rendered
asynchronously via a new `/api/strategy/<id>/backtest-trades` endpoint.

**Rejected:**
- SSR via render_template(): blocks initial HTML render, doubles TTFB
- Threading backend calls: unnecessary complexity, worker pool risk

## Changes

- `strategy_runner.py`: `run_30d_backtest()` gains `return_raw=False`
  parameter. When True, returns `(stats, raw_results)` tuple. All
  existing callers unaffected.
- `app.py`: New `GET /api/strategy/<id>/backtest-trades` endpoint.
  Hydrates strategy config, calls `run_30d_backtest(return_raw=True)`,
  filters `DATA_INVALID` rows, shapes View Model
  (signal_time, direction, entry_price, exit_price, result,
  exit_reason, pnl), reverses to newest-first, returns JSON.
- `templates/trades.html`: Blotter section added below merged table.
  Async JS fetch populates table on page load. Loading skeleton shown
  during fetch.

## Consequences

- Raw backtest ledger visible in UI — signal count, timestamps, and
  exit reasons immediately auditable.
- No impact on TTFB — blotter loads asynchronously.
- `DATA_INVALID` rows filtered at API boundary — frontend receives
  only valid executed trades.
- Full 30d window shown regardless of go_live_at — consistent with
  dashboard card signal count.
- `exit_reason` column exposes TP/SL/TIMEOUT classification per trade.

## Negative Space

- Does NOT change `_aggregate_sim()`.
- Does NOT filter blotter by go_live_at.
- Does NOT add pagination — all 30d signals returned.
- Does NOT change the merged Theo/OANDA table above the blotter.
