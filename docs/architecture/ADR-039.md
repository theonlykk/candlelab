# ADR-039 — Fix OPEN Trade Handling in Simulation Engine

**Date:** 2026-05-01
**Status:** Accepted
**Repo:** theonlykk/candlelab
**Author:** Khalid Khan (Lead Engineer)
**Reviewer:** Gemini (Staff Architect)

---

## Context

`_scan_tp_sl_timeout()` in `simulation_engine.py` could not distinguish
between "timeout reached" and "no more candle data available." When
forward bars were exhausted before `bars_remaining` was reached, it
fell through to `_timeout_result_class()` and returned TIMEOUT
WIN/LOSS/BREAKEVEN. This caused live trades (still open in OANDA) to
appear as resolved in the Theo blotter after only a few bars.

Confirmed example: Sharp Violet Falcon (M15, timeout=20) showed Theo
TIMEOUT LOSS after 2 M15 bars while OANDA correctly held the trade
open for 19 M15 bars.

## Decision

Add `data_exhausted` flag to the forward scan loop. When the loop
breaks due to `bar_idx >= n` (data exhausted), return `result="OPEN"`
sentinel instead of a premature TIMEOUT result.

**`oanda-trading` uses wall-clock timeout** (`timeout_at = signal_ts +
timedelta(minutes=minutes_per_bar * timeout_bars)`). This is correct
for a live executor operating in real-time. `candlelab` correctly uses
bar-count timeout for the backtester — the two are equivalent when
sufficient candle data exists.

## Changes

- `simulation_engine.py`: `data_exhausted` flag added to forward scan
  loop. Fallthrough block now returns `result="OPEN"` when data
  exhausted, preserving existing TIMEOUT logic for natural loop
  completion.
- `app.py`: `api_strategy_backtest_trades` filters `"OPEN"` alongside
  `"DATA_INVALID"` — open trades excluded from historical blotter.
- Chart adapter: no change needed — `exit_time=None` guard already
  excludes OPEN trades.
- `_aggregate_sim()`: no change needed — already filters to
  WIN/LOSS/BREAKEVEN only.

## Consequences

- Live trades no longer appear as premature TIMEOUT in Theo blotter.
- `result="OPEN"` is a valid financial state, distinct from
  `result="DATA_INVALID"` (data integrity failure).
- `pnl_dollars=None` for OPEN trades — unrealised P&L is the
  executor's domain, not the simulator's.
- Since-live blotter will show blank exit columns for open trades
  (future enhancement: render open trade rows distinctly).

## Negative Space

- Does NOT change `oanda-trading` executor timeout logic.
- Does NOT calculate unrealised P&L for open trades.
- Does NOT render open trade panels on the chart.
- Does NOT change `_aggregate_sim()`.
