# ADR-041 — P&L Attribution Model with Local DB Rate Sourcing

**Date:** 2026-05-01
**Status:** Accepted (Revision 3)
**Repo:** theonlykk/candlelab
**Author:** Khalid Khan (Lead Engineer)
**Reviewer:** Gemini (Staff Architect)

---

## Context

Comparing Theo P&L (USD) directly to OANDA realized P&L (CAD) obscures
two independent sources of variance:
1. Execution slippage — entry/exit price differences
2. FX conversion — unknown rate OANDA uses to settle in CAD

Previous revisions used broker-provided `pnl_pips` (spread-inclusive)
and a live OANDA API call for CAD/USD rate — both wrong.

## Decision

P&L Attribution Model using local PostgreSQL M5 sourcing.

**Three baselines:**
- `Theo P&L (USD)`: simulated pips × static PIP_VALUES × units
- `OANDA Eq (USD)`: `(fill - exit) / pip_size` × PIP_VALUES × units
  — gross price movement only, no broker spread/fees
- `OANDA Real (USD)`: `oanda_pl_cad × cad_usd_rate_at_close`
  — settled ground truth converted at close time

**Two deltas:**
- `Exec Delta`: OANDA Eq − Theo — pure execution slippage
- `FX Delta`: OANDA Real − OANDA Eq — FX conversion approximation

**Rate sourcing:** Single query to `oanda_candles` (instrument=USD_CAD,
granularity=M5) covering the 35-day window. O(1) dict lookup per trade
at the floored M5 timestamp of `closed_at`. Zero external API calls.

## Verified Example

Sharp Violet Falcon 30/04 22:30 SELL (NZD/USD, 75k units):
- Theo: 2.7 pips → -$20.25 USD ✅
- OANDA Eq: 3.5 pips → -$26.25 USD ✅
- Exec Delta: -$6.00 (0.8 pip slippage) ✅
- OANDA Real: -$35.81 CAD × 0.73674 = -$26.39 USD ✅
- FX Delta: -$0.14 (rate precision) ✅

## Consequences

- Zero external OANDA API calls on page load
- Exec Delta isolates execution quality per trade
- FX Delta will be non-zero for ALL pairs — OANDA always settles
  in account currency (CAD) using its own internal rate
- Open trades show — for Realized USD and FX Delta (no closed_at)

## Negative Space

- Does NOT change oanda_pl in the DB
- Does NOT change the executor
- Does NOT convert _fetch_true_pnl() to USD
- _fetch_cad_usd_rate() deleted — no longer needed
