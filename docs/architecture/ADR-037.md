# ADR-037 — Strategy Chart Window Alignment and Live Trade Overlay

**Date:** 2026-04-30
**Status:** Accepted
**Repo:** theonlykk/candlelab
**Author:** Khalid Khan (Lead Engineer)
**Reviewer:** Gemini (Staff Architect)

---

## Context

`strategy_chart` had two bugs:

1. Window anchor used `datetime.now()` — a rolling window that diverged
   from `run_30d_backtest()`'s fixed `go_live_at` anchor. The signal
   at 2026-03-31 15:55 was included in the backtest card but excluded
   from the chart because the rolling window had advanced past it.

2. Chart showed only 30d backtest panels. Since-live Theo trades were
   not rendered, leaving the user blind to live forward-test performance
   on the chart page.

## Decision

Sub-option B1 — Single `render_trade_panels()` call with combined
backtest + since-live trade list, sorted chronologically.

`render_trade_panels()` already has a built-in LIVE/BACKTEST overlay
using `go_live_at`. Panels before `go_live_ts` are stamped "BACKTEST",
panels after are stamped "LIVE". A single chronologically sorted list
provides the best UX — continuous narrative from historical to live.

**Rejected:**

- Sub-option B2 (two calls, stacked): redundant, ignores existing
  renderer capabilities, breaks chronological narrative.

## Changes

- `app.py`: `strategy_chart` window anchor changed from rolling `now()`
  to fixed `go_live_ts` (null-safe via `anchor_ts_chart`). Both
  `from_ts_chart` and `strict_cutoff` now match `run_30d_backtest()`
  exactly.
- `app.py`: Since-live trades fetched via `run_since_live_detail()`,
  run through same adapter as backtest trades (using full `df.index`
  for `get_indexer`), merged and sorted chronologically.
- `app.py`: `render_trade_panels()` receives full concatenated `df`
  (pre_live + live) for unbroken OHLC context across both periods.

## Consequences

- Chart panel count matches 30d backtest card signal count exactly.
- Live forward-test trades visible on chart, stamped "LIVE".
- Chronological panel progression: BACKTEST → LIVE.
- Window is fixed: `[go_live_ts - 30d, go_live_ts]` for backtest,
  `[go_live_ts, now]` for live.
- If `run_since_live_detail()` fails, backtest panels still render.
  Failure is logged and swallowed.

## Negative Space

- Does NOT change `render_trade_panels()`.
- Does NOT change `run_30d_backtest()` or `run_since_live_detail()`.
- Does NOT change `simulation_engine.py`.
- Does NOT add a second image strip.
- `signals_df` still computed from `pre_live_df` only — pattern
  detection runs on backtest window only, not live window.
