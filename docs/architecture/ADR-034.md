# ADR-034 — Strategy Chart Signal Alignment with 30d Backtest

**Date:** 2026-04-30
**Status:** Accepted
**Repo:** theonlykk/candlelab
**Author:** Khalid Khan (Lead Engineer)
**Reviewer:** Gemini (Staff Architect)

---

## Context

`strategy_chart` used `_simulate_trades()` — a parallel simulation
engine diverging from `run_simulation()` in `simulation_engine.py`
on position sizing, fill logic, and P&L math. It also had four signal
detection divergences from `run_30d_backtest()`:

1. `continuation` not passed to `detect_signal()` — anchor-only
   signals fired for continuation strategies
2. `indicator_fn=None` — indicator filter not applied
3. Full concatenated df (pre_live + live) used for signal detection
   instead of 30d window only
4. Session filter applied inside simulation not before it

Result: chart showed far more panels than the 15 backtest signals
on the My Strategies card.

## Decision

Option C — Extract shared signal detection into aligned path.
`strategy_chart` now calls `run_simulation()` with identical signal
detection parameters as `run_30d_backtest()`.

**Rejected:**
- Option A (use run_30d_backtest() directly): returns aggregated
  stats, not raw trade objects needed by render_trade_panels()
- Option B (fix four divergences inline): two divergent code paths
  guaranteed to drift again

## Changes

- `app.py`: `strategy_chart` signal detection block replaced.
  Uses `pre_live_df` only for signal detection and simulation.
  Passes `continuation`, indicator filter, session filter consistent
  with `run_30d_backtest()`. Calls `run_simulation()` instead of
  `_simulate_trades()`.
- Thin adapter maps `run_simulation()` output to
  `render_trade_panels()` shape. Uses `get_indexer(method='pad')`
  for wall-clock timestamp alignment. Caps `exit_idx` at
  `len(pre_live_df) - 1` for trades exiting beyond window —
  never dropped.
- `render_trade_panels()` receives `pre_live_df` as primary df.
  MA series alignment uses full concatenated df for visual context.

## Consequences

- Chart panel count matches 30d backtest signal count exactly.
- Single simulation engine (`run_simulation()`) for chart path.
- Trades exiting beyond 30d window render as open at right edge.

## Negative Space

- Does NOT delete `_simulate_trades()` — still used by wizard
  routes via `_backtest_pattern` (line 509). Wizard unification
  is a future ADR.
- `_backtest_pattern_multi_timeout` (line 549) is dead code —
  no active route calls it. Flagged for removal in a future ADR.
- Does NOT change `simulation_engine.py`.
- Does NOT change `run_30d_backtest()`.
- Does NOT change `render_trade_panels()`.

## Follow-On

- Future ADR: unify wizard routes to use `run_simulation()`
  and delete `_simulate_trades()`
- Future ADR: remove dead `_backtest_pattern_multi_timeout`
